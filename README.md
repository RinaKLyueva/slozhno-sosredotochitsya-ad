# Сложно сосредоточиться

Адаптивный лонгрид о том, почему людям трудно концентрироваться и что с этим делать. У сайта две цветовые темы, светлая «День» и тёмная «Неон», и режим «Авто», который подстраивается под системные настройки пользователя.

## О проекте

Это проектная работа, в которой я сверстала страницу по макету почти с нуля: в заготовке были только файловая структура, шрифты, картинки, блок кнопок переключения темы и скрипт для него. Разметку, перенос контента и все стили я написала сама.

В отличие от предыдущих работ, здесь главная задача — две темы, которые переключаются и автоматически, по системным настройкам, и принудительно, кнопками на странице. Ещё одна особенность — адаптивная «резиновая» вёрстка под мобильные, планшеты и десктоп по подходу Mobile First.

## Что сделано

- **Три темы.** Цвета вынесены в CSS-переменные и переопределяются в `dark.css` и `light.css`. Кнопки «День» и «Неон» вешают на `<html>` классы `theme-light` и `theme-dark`. В режиме «Авто» работает медиафича `prefers-color-scheme`. Класс с темой сильнее медиазапроса по специфичности, поэтому выбор пользователя всегда побеждает системную настройку.
- **Адаптив по Mobile First.** Основные стили написаны для мобильных, медиазапросы от 768px и от 1024px перестраивают сетку под планшет и десктоп. Размер главного заголовка плавно меняется через `clamp()`.
- **Лейаут на гридах.** Секции с текстом, раскладка карточек и галерея собраны на CSS Grid, без лишних обёрток.
- **Декоративные элементы через псевдоэлементы.** Уголки в шапке и подвале описаны в общем классе `decorated-zone`, точка у надписи REC — через `::after`. Надпись REC видна только в тёмной теме и скрыта от скринридеров через `aria-hidden`.
- **Фон страницы** закреплён через `background-attachment: fixed` и меняется вместе с темой.
- **Состояния интерактивных элементов:** `:hover`, `:focus-visible` и выбранное состояние у кнопок темы, подчёркивание и обводка у ссылок.
- **Оптимизация:** ленивая загрузка картинок галереи, фавиконки в трёх форматах.

## Технологии

- HTML5, семантическая разметка
- CSS3: Grid, Flexbox, CSS-переменные, медиазапросы `prefers-color-scheme`, `clamp()`, псевдоэлементы, `color-mix()`
- JavaScript — готовый скрипт переключения тем из заготовки

## Как запустить

1. Склонируйте репозиторий:

   ```bash
   git clone git@github.com:RinaKLyueva/slozhno-sosredotochitsya-ad.git
   ```

2. Откройте `index.html` в браузере или запустите его через расширение Live Server в VS Code.

Сборка и установка зависимостей не нужны. Проверено в Google Chrome, Firefox и Яндекс Браузере.

Чтобы проверить автоматическую тему, включите режим «Авто» и переключайте `prefers-color-scheme` в инструментах разработчика Chrome: **⋮ → More tools → Rendering → Emulate CSS media feature prefers-color-scheme**.

```
    ├── dark.css         — тёмная тема
    └── light.css        — светлая тема
```
